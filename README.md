## Deskripsi Project
My Store adalah aplikasi toko online sederhana. Pada UTS ini ditambahkan
fitur Login Admin dan Dashboard Admin untuk mengelola produk (CRUD).

## Fitur
1. Login Admin (session PHP)
2. Dashboard Admin
3. Create produk baru
4. Update produk
5. Delete produk (discontinued)
6. 25 data dummy produk

## Teknologi
PHP Native, MySQL, Bootstrap 5, XAMPP

## Cara Menjalankan
1. Pindahkan folder ke `htdocs` (XAMPP)
2. Import `database.sql` lewat phpMyAdmin
3. Buka `http://localhost/my-store/login.php`
4. Login: **admin / admin123**
